## `// projects.exe`

### 💸 FinFlow

> Financial backend built around real business rules instead of a basic CRUD.

`Java` `Spring Boot` `PostgreSQL` `JPA` `Docker` `Swagger`

**Inside the project**

- income and expense management
- financial transaction lifecycle
- status control
- financial dashboard
- validations and exception handling
- REST API architecture

---

### 🚚 RouteFlow

> Logistics platform focused on delivery flows, vehicles, drivers and object-oriented design.

`Java` `Spring Boot` `PostgreSQL` `Strategy Pattern` `Docker`

**Inside the project**

- driver management
- vehicle availability
- delivery lifecycle
- freight calculation strategies
- business validations
- Strategy Pattern
- object-oriented architecture

---

### 🔐 AccessHub

> Identity and access management backend focused on application security.

`Java` `Spring Boot` `Spring Security` `JWT` `PostgreSQL`

**Inside the project**

- JWT authentication
- refresh tokens
- role-based access control
- account lockout
- audit trail
- BCrypt password hashing
- authentication filters
